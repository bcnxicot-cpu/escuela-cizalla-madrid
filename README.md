# Escuela Cizalla — propuesta web

Landing editorial para Escuela Cizalla, taller y escuela de encuadernación artesanal en Madrid.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run lint
npm test
```

La propuesta utiliza datos e imágenes públicas del negocio exclusivamente como demostración comercial. Antes de una publicación definitiva deben revisarse y aprobarse los contenidos y derechos de uso con Escuela Cizalla.
